add splitters between the item lists so i can adjust the height of the 3 lists.

## Plan

All changes are in `templates/index.html` only — no server changes needed.
Panel heights are a pure UI preference so `localStorage` is sufficient (no SQLite round-trip).

### 1 — HTML
Insert a `<div class="panel-splitter">` between each adjacent panel pair inside `#panels-container`:

```
#panel-main
<div class="panel-splitter" id="split-main-favs"></div>
#panel-favs
<div class="panel-splitter" id="split-favs-ignr"></div>
#panel-ignr
```

Remove the `border-top` rules from `#panel-favs` and `#panel-ignr` (the splitter div replaces them visually).

### 2 — CSS
```css
.panel-splitter {
  flex: 0 0 6px;
  background: #dee2e6;
  cursor: ns-resize;
  position: relative;
}
.panel-splitter::after {              /* subtle grip dots */
  content: '';
  position: absolute;
  left: 50%; top: 50%;
  transform: translate(-50%, -50%);
  width: 24px; height: 3px;
  border-top: 1px solid #adb5bd;
  border-bottom: 1px solid #adb5bd;
}
.panel-splitter:hover, .panel-splitter.dragging {
  background: #6ea8fe;
}
```

Panels switch from proportional `flex: N` to pixel `flex: 0 0 <px>` as soon as heights are known, so drag arithmetic is straightforward. Add `min-height: 36px` to `.panel`.

### 3 — JS (drag logic)
```
PANEL_HEIGHTS_KEY = 'panelHeights'   // localStorage key

initPanelHeights()
  stored = localStorage.getItem(PANEL_HEIGHTS_KEY)
  if stored → apply saved px values to the 3 panels as flex-basis
  else      → leave flex:3 / flex:6 / flex:1 (initial render), then
              after first paint snapshot offsetHeights and apply as px

splitter mousedown:
  record startY, topPanel, botPanel, topStart (offsetHeight), botStart
  add 'dragging' class, disable user-select on body

document mousemove (only while dragging):
  dy = clientY - startY
  newTop = max(36, topStart + dy)
  newBot = max(36, botStart - dy)
  topPanel.style.flex = `0 0 ${newTop}px`
  botPanel.style.flex  = `0 0 ${newBot}px`

document mouseup:
  remove dragging state
  save current heights to localStorage
```

### 4 — Persistence key structure
```json
{ "main": 220, "favs": 440, "ignr": 80 }
```
Stored under `panelHeights` in `localStorage`.

### Constraints
- Min panel height: 36 px (just enough to show the header bar).
- Both splitters are independent drag targets.
- Heights are restored on every page load before content renders.
